    How to install click-lock vinyl plank flooring

    Here’s the practical path for floating click-lock LVP. Work from a chalk line, keep expansion gaps, stagger end joints, and seat every lock fully before moving on.

    Glue-down is a different skill set (adhesive open time, trowel notches, roller pressure). Treat it as advanced — hire a flooring installer, or follow the manufacturer’s glue-down instructions carefully if that’s what you bought.
    1. Snap a starter line — walls aren’t square. Dry-lay the first row with spacers at the wall.
    2. Angle and click — most systems angle the long side in, then drop/tap flat. Follow your profile’s diagram.
    3. Tap, don’t smash — tapping block + rubber mallet on long joints; pull bar at the wall.
    4. Stagger end joints — typically at least 6–8 in (or per brand) between rows so seams don’t line up.
    5. Cut the last plank of each row — use leftover as the start of the next row when the length works.
    6. Door jambs — undercut with an oscillating tool so the plank slides under; leave expansion space under the casing.
    7. Last row — rip to width, leave the expansion gap, then seat it with a pull bar.
    8. Transitions — install track/strip at doorways after the field is down (or per brand sequence).

    Mix planks from several boxes as you go so shade variation blends. Keep a scrap cart for small cutoffs and a spare full box sealed for future repairs.

    Install FAQ

    How big should the expansion gap be for LVP?

    Use the gap on your install sheet. Many brands call for about 1/4 inch at walls and fixed objects. Spacers hold it while you work, and baseboards or quarter-round cover it after.

    Can you install LVP under kitchen cabinets?

    Usually not. Most brands say cabinets, islands, and other heavy fixed items should not sit on a floating floor, because the floor needs to move. Install the planks up to the cabinets and leave the expansion gap there too.

    How far apart should LVP end joints be?

    Typically at least 6 to 8 inches between rows, or whatever your brand specifies. Random-looking staggers look more like real wood than a repeating stair-step pattern.
