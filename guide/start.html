    Chapter 1

    Start here

    Before you dive into install day, figure out what you already have and which tool answers the next question. Five minutes here can keep you from buying the wrong floor.

    1. Identify what’s on the floor now

    Use the free photo report on the home page: snap 1–3 close-ups of seams, edges, and texture, then answer a short checklist. You get a plain-English guess (click-lock LVP vs tile vs wood, for example) — not AI vision and not a licensed inspection.

    Open photo report — is it vinyl? →

    2. Pick the DIY tool that fits

    • Still identifying? Stay on the photo report.
    • Ready to order sizes? Go to Measure for length × width and waste.
    • Want a record of the room? Save photos in the project gallery. They stay in this browser.
    This guide focuses on click-lock LVP for DIY. Glue-down vinyl shows up later as an advanced path — most homeowners should stick with floating click-lock.

    3. Then follow the chapters in order

    Understand the product → check if vinyl fits the room → gather tools → measure → prep → install → finish → troubleshoot. Skip ahead only if you already know the earlier material.
