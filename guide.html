DIY path

Vinyl plank flooring, beginner to confident DIY

A practical path from “what is this floor?” through a confident click-lock install. Plain English, tied to the free DIY tools on this site.

What this is for

Help you figure out what you already have, pick the right LVP for the room, gather tools, measure and prep honestly, then install click-lock flooring without guessing. Some jobs still need a hired installer (moisture, major leveling, baths/stairs) — this guide tells you when to pause.
