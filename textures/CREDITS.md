# Texture credits

Seamless wood-floor color maps from [ambientCG](https://ambientcg.com/), released under
[CC0 1.0](https://docs.ambientcg.com/license/) (public domain; no attribution required, credited here anyway).
Downloaded as 1K JPG color maps via the ambientCG public download API and recompressed for the site
(progressive mozjpeg, metadata stripped). "Color-graded" means the tone was adjusted with Pillow
(saturation / brightness / channel balance only) so the sample matches the look's name.
